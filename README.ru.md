## О курсе

**Introduction to Julia** — это практический курс для программистов, которые хотят изучить Julia через исполняемые примеры, а не только через теорию.

Курс начинается с основ языка и постепенно переходит к темам, в которых Julia особенно сильна: научные вычисления, численные методы и производительное программирование.

В программе:

- строки и Unicode;
- структуры данных и управляющие конструкции;
- функции и broadcasting;
- управление пакетами и воспроизводимые окружения;
- построение графиков и визуализация;
- множественная диспетчеризация;
- бенчмаркинг и анализ производительности;
- численная линейная алгебра;
- матричные разложения.

Все занятия оформлены как Jupyter Notebook. Каждый ноутбук сочетает объяснения, исполняемые примеры, задания, готовые решения и автоматическую проверку результатов.

Материалы основаны на курсе JuliaAcademy *Introduction to Julia* и были существенно переработаны, расширены, проверены и актуализированы для Julia **1.11.3**. В текущую редакцию также добавлены углублённые материалы по производительности, численной линейной алгебре и матричным разложениям.

## Результаты обучения

После прохождения курса вы сможете:

- **писать идиоматичный код на Julia** — использовать переменные, строки, управляющие конструкции, функции, анонимные функции, broadcasting и соглашения о мутации;
- **работать с основными структурами данных Julia** — кортежами, именованными кортежами, словарями, векторами, матрицами и массивами;
- **корректно работать со строками Unicode** и понимать разницу между обходом символов и индексированием UTF-8;
- **использовать множественную диспетчеризацию как инструмент проектирования**, а не только как синтаксический механизм перегрузки методов;
- **управлять пакетами и воспроизводимыми окружениями** с помощью `Pkg`, `Project.toml` и `Manifest.toml`;
- **строить графики и визуализации** с помощью `Plots.jl` и различных backend-ов;
- **корректно измерять производительность Julia-кода** с помощью `BenchmarkTools.jl` и понимать влияние компиляции, аллокаций, стабильности типов и порядка доступа к памяти;
- **решать задачи численной линейной алгебры** — работать с векторами, матрицами, нормами, определителями, системами линейных уравнений и структурированными матрицами;
- **выбирать и применять матричные разложения**, включая LU, QR, Cholesky, SVD и спектральное разложение.

## Для кого этот курс

Курс рассчитан на тех, кто уже умеет программировать и хочет добавить Julia в свой профессиональный инструментарий.

### Требования

| Требование | Уровень |
|---|---|
| Опыт программирования | **Обязателен.** Подойдёт Python, MATLAB, R, C, C++, Java или другой язык. |
| Владение русским языком | **Обязательно для чтения объяснений.** |
| Знакомство с Jupyter | **Желательно.** Основы разбираются в уроке 1. |
| Линейная алгебра | **Желательна для уроков 11–13.** Необходимые основы вводятся в уроке 11. |
| Опыт работы с Julia | **Не требуется.** |

Этот курс **не является первым курсом по программированию**. Предполагается, что вы уже знакомы с такими понятиями, как переменные, циклы, условия и функции.

## Установка

### 1. Установите Julia

Все ноутбуки проверены на **Julia 1.11.3**.

Для Linux и macOS через `juliaup`:

```bash
curl -fsSL https://install.julialang.org | sh
juliaup add 1.11.3
juliaup default 1.11.3
```

Проверьте установку:

```bash
julia --version
```

Ожидаемый результат:

```text
julia version 1.11.3
```

В Windows можно установить Julia через `juliaup` из Microsoft Store или использовать официальный установщик со страницы [Julia Downloads](https://julialang.org/downloads/).

---

### 2. Клонируйте репозиторий

```bash
git clone https://github.com/Cartesian-School/Introduction-to-Julia.git
cd Introduction-to-Julia
```

---

### 3. Восстановите окружение курса

Из корня репозитория:

```bash
julia --project=. -e 'using Pkg; Pkg.instantiate()'
```

Команда устанавливает зависимости, зафиксированные в `Project.toml` и `Manifest.toml`.

> Первый запуск может занять несколько минут из-за предварительной компиляции некоторых пакетов.

---

### 4. Установите Jupyter kernel

```bash
julia --project=. -e 'using Pkg; Pkg.add("IJulia"); using IJulia'
```

Если Jupyter ещё не установлен, `IJulia` может предложить установить отдельное окружение Miniconda.

---

### 5. Запустите ноутбуки

Через IJulia:

```bash
julia --project=. -e 'using IJulia; notebook(dir=".")'
```

Или, если Jupyter уже установлен:

```bash
jupyter lab
```

## Как работать с курсом

Проходите уроки по порядку.

Внутри ноутбука:

- запускайте ячейки сочетанием **`Shift+Enter`**;
- выполняйте ячейки сверху вниз;
- задания помечены как `✅ Задание N.M`;
- место для собственного решения помечено как `# Ваше решение`;
- готовое решение помечено как `# Правильное решение`;
- проверка обычно выполняется через `@assert` или другую исполняемую проверку.

Успешный `@assert` обычно не выводит ничего.

Некоторые исключения создаются **намеренно в учебных целях**. В таких местах причина ошибки объясняется непосредственно рядом с соответствующей ячейкой.

## Проверка курса

В репозитории есть валидатор уровня всего курса:

```bash
python3 tools/check_course.py
```

Он проверяет, в частности:

- корректность JSON ноутбуков;
- соответствие Julia kernel;
- последовательность `execution_count`;
- отсутствие неожиданных error outputs;
- наличие целей урока и навигации;
- структуру «задание / решение»;
- корректность нумерации упражнений;
- внутренние ссылки;
- отсутствие абсолютных локальных путей;
- отсутствие случайно попавших секретов или credential-подобных данных.

Сам валидатор также тестируется на намеренно повреждённых данных:

```bash
python3 tools/test_check_course.py
```

Эти проверки интегрированы в CI.

## Примечания по выполнению

### Намеренные исключения

Некоторые уроки специально вызывают исключения для демонстрации поведения Julia, включая:

- `MethodError`
- `ParseError`
- `StringIndexError`
- `KeyError`
- `DimensionMismatch`
- `PosDefException`

Такие ошибки считаются допустимыми только там, где они явно объяснены в учебном тексте рядом с соответствующей ячейкой.

### `PyCall` в уроке 10

На некоторых Linux-системах `PyCall` может не собраться, если выбранная установка Python не предоставляет совместимую shared-библиотеку `libpython`.

Если возникает соответствующая ошибка, можно пересобрать `PyCall` с использованием управляемого Python-окружения:

```julia
ENV["PYTHON"] = ""
using Pkg
Pkg.build("PyCall")
```

После этого перезапустите Julia kernel.

Применяйте этот способ только при наличии соответствующей ошибки сборки.

## Участие в разработке

Issues и pull requests приветствуются.

Перед отправкой изменений:

1. перезапустите kernel изменённого ноутбука;
