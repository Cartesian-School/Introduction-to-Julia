## О курсе

**Julia с нуля** — практический курс языка Julia, подготовленный **Cartesian School** для людей, которые уже знакомы с базовыми понятиями программирования и хотят изучить Julia с самого начала: от синтаксиса и структур данных до высокопроизводительного программирования, линейной алгебры, численных методов и полноценного итогового проекта.

«С нуля» здесь означает **с нуля именно в Julia**, а не первый опыт программирования. Предварительное знание Julia не требуется, однако предполагается понимание таких понятий, как переменная, функция, цикл, условная конструкция и базовый тип данных.

Курс содержит **15 уроков, пронумерованных от Lesson 0 до Lesson 14**. Материал последовательно ведёт от первого notebook-файла к итоговому проекту **ThermalLab**, объединяющему моделирование, multiple dispatch, визуализацию, анализ производительности, линейную алгебру и численные методы.

Русская версия курса находится в каталоге [`RU/`](RU/).

## Публичный курс и цель проекта

Репозиторий открыт публично, чтобы упростить изучение Julia и способствовать распространению языка и его экосистемы — в том числе среди русскоязычных программистов, студентов и инженеров.

Автор курса стремится поддерживать сообщество Julia посредством:

- создания доступных учебных материалов на русском языке;
- демонстрации практического применения Julia в программировании, научных вычислениях и численных методах;
- публикации примеров, упражнений и проектов, которые можно самостоятельно запускать и анализировать;
- поощрения дальнейшей работы с официальной документацией и пакетами экосистемы Julia.

## Чему вы научитесь

После завершения курса вы сможете:

- писать понятный и идиоматичный код на Julia;
- работать со строками Unicode, кортежами, словарями, множествами, векторами и матрицами;
- использовать циклы, условные конструкции, comprehensions, broadcasting и итераторы;
- проектировать функции с позиционными, именованными, необязательными аргументами и varargs;
- понимать различие между функцией и методом;
- применять **multiple dispatch** как механизм проектирования расширяемого API;
- управлять пакетами и окружениями через `Pkg`, `Project.toml` и `Manifest.toml`;
- строить графики и анализировать данные с помощью `Plots.jl`;
- корректно измерять производительность и интерпретировать benchmark-и;
- понимать влияние JIT, аллокаций, стабильности типов и локальности памяти;
- выполнять практические вычисления линейной алгебры;
- решать системы уравнений оператором `\`;
- применять LU, QR, Cholesky, SVD, EVD и разложение Шура;
- использовать специальные структуры матриц;
- анализировать численные ошибки, conditioning и устойчивость;
- реализовывать базовые методы поиска корней, численного интегрирования и численного дифференцирования;
- решать простые ODE методами Euler и RK4;
- создавать полноценный проект, объединяющий модель данных, алгоритмы, тесты, производительность, визуализацию и отчётность.

## Итоговый проект — ThermalLab

Lesson 14 объединяет материал всего курса в одном проекте.

**ThermalLab** моделирует процесс охлаждения по закону Ньютона и включает:

- собственные типы `ThermalModel`, `MeasurementSet` и `SimulationResult`;
- абстрактный интерфейс интегратора;
- реализации Euler и RK4 через multiple dispatch;
- генерацию синтетических измерительных данных;
- оценку параметра модели методом least squares;
- residuals, MAE, RMSE и `R²`;
- сравнение точности и вычислительной стоимости;
- опциональную визуализацию через `Plots.jl`;
- экспорт результатов в CSV;
- контрактные тесты и валидацию данных.

Проект демонстрирует полный рабочий процесс:

> **проблема → модель → код → вычисления → валидация → результат**

## Установка

### 1. Установите Julia

Курс развивается для серии **Julia 1.11.x**.

Текущее `Project.toml` задаёт совместимость с Julia `1.11`, а зафиксированное окружение в `Manifest.toml` было разрешено с использованием Julia **1.11.3**.

Официальные инструкции по установке:

<https://julialang.org/downloads/>

После установки проверьте версию:

```bash
julia --version
```

### 2. Клонируйте репозиторий

```bash
git clone https://github.com/Cartesian-School/Julia-from-zero.git
cd Julia-from-zero
```

### 3. Восстановите окружение

```bash
julia --project=. -e 'using Pkg; Pkg.instantiate()'
```

Репозиторий использует:

- `Project.toml` — объявленные зависимости;
- `Manifest.toml` — разрешённые и зафиксированные версии зависимостей.

### 4. Запустите Jupyter

Если вы используете IJulia:

```bash
julia --project=. -e 'using IJulia; notebook(dir=".")'
```

или:

```bash
jupyter lab
```

После запуска откройте каталог `RU/` и начните с:

[`RU/Lesson_0_Julia_Cartesian_School_RU.ipynb`](RU/Lesson_0_Julia_Cartesian_School_RU.ipynb)

## Как работать с курсом

Проходите notebook-файлы последовательно от **Lesson 0** до **Lesson 14**.

Рекомендуемый порядок работы:

1. прочитайте цель раздела;
2. запустите пример;
3. проанализируйте результат;
4. самостоятельно выполните задание;
5. только после этого сравните своё решение с примером;
6. проверьте `@assert` и итоговый checkpoint;
7. прежде чем переходить дальше, убедитесь, что понимаете причину работы кода, а не только его синтаксис.

В курсе используется единый дидактический шаблон:

| Элемент | Значение |
|---|---|
| **Цель** | результат данного фрагмента |
| **Теория** | определение или правило |
| **Пример** | исполняемый код |
| **Анализ** | интерпретация работы |
| **Важно** | существенное правило |
| **Типичная ошибка** | распространённая проблема |
| **Попробуйте сами** | короткий эксперимент |
| **Практика** | самостоятельное задание |
| **Итоги** | ключевые выводы |

## Воспроизводимость и безопасность окружения

Курс проектируется так, чтобы примеры, связанные с пакетами, не изменяли неявно окружение проекта.

В частности:

- notebook не должен автоматически выполнять `Pkg.add(...)` без явной необходимости;
- эксперименты с пакетами могут использовать временные окружения;
- зависимости проекта следует восстанавливать через `Pkg.instantiate()`;
- код, использующий опциональные пакеты, должен предсказуемо работать и тогда, когда такой пакет не установлен.
